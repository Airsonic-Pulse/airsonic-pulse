# Airsonic-Pulse v13.3.0-rc.1

## Upgrade notes

First release candidate of the 13.3 line. This is a backend-improvement and fix release; the visible changes are new General Settings fields and the version shown on the login screen.

The testing window is one to two weeks; report findings as issues against milestone 13.3.x. The WAR reports 13.3.0-SNAPSHOT on the login page; that is expected for release candidates and changes at the final.

- Two Liquibase changesets run on first start (liquibase/13.3): `lyrics.source_last_modified`, nullable, used to invalidate the lyrics cache when a sidecar file or tag changes (#281); and `play_queue_file.position`, with a backfill of existing saved queues from id order (#214). Back up the database before upgrading. Downgrading to 13.2.x after these changesets have run is not supported.
- The first scan after upgrading may remove genres that no longer appear on any file (#319) and refreshes album-folder metadata where a track was retagged since the folder was last read. Expect genre and folder-level changes after that scan.
- General Settings gains fields for the ReplayGain fallback (#252) and the scan timeouts (#208); existing property values are honoured.
- Saving General Settings no longer re-imports playlists unless the playlist folder changed (#382); clearing the folder now stops its watcher (#394).

## Summary

Fixes users will notice: Play all on the Starred page (#371) and playing a playlist entry whose file went missing (#402) no longer fail with an UnsupportedOperationException; play-queue WebSocket sessions no longer create ownerless players (#354); the lyrics cache now notices changed sidecar files and tags (#281); genres no longer linger after their last file is retagged or removed (#319); three null-duration crashes in play-count, XSPF and Sonos paths are guarded (#322); shuffle play of a folder picks its songs with one database query instead of walking the whole subtree (#351).

Hardening: count and size parameters are clamped, including cover-art size which could request an unbounded image (#286); podcast refresh persists episodes on the refresh thread instead of parallel workers (#353); the apiKey audit log distinguishes unknown, disabled and expired keys (#284).

Internal: remaining commons-lang 2.x usages migrated to lang3 (#180); a build-time check against mutation of immutable list returns (#302); an i18n completeness test with 32 drifted bundle keys fixed (#299); test-fixture hygiene and two test classes that had never run (#266, #395); the unused /ext controller prefix dropped (#335); a parser-strategy decision record added.

This is the first preview of the 13.3 line; rc.1 contains the full set of changes described above.

## Known issues

None affecting users at the time of the cut.
